# 概念图登记

## 最新版本

`printed-book-spread.png` 为有真实导读排版的跨页，使用内置 ImageGen 生成。已经检查正文、三类原语、下划线锚点和书籍材质。左右页均有内容，取代旧分镜中的空白页。当前跨页为近景概念参考，正式开书还需匹配同一机位的闭合首帧。

最新提示词见 `../source/motion-prompts-v2.md`；全程媒体范围见 `../全程动效设计.md`。

`full-motion-storyboard.png` 为全程纸艺动效概念板。已经修正初稿自行添加的原语解释，统一为选择、是的概率和有序评分，并将街区限定为两家书店与一家剧场。阶梯上的 1、2、3 是视觉顺序标识，不是 API 分数或模型返回结果。正式图解将使用明确等级描述与实际接口索引。

概念板里的政策摘要线条表示版式区域，生产图要替换为剧本中的完整虚构政策文字。首尾生产帧不能直接从拼图裁切；书店内部的装饰文字也需要在正式素材中重新校对。图中没有真实交易数据或实验结果。

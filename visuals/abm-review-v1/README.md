Four Image Gen reference pages replace the existing single crowded ABM page in the proposed structure. The application has NOT been changed.

Selected pages:
- 11-town-introduction.png — town, cast, and coupon rules.
- 12-resident-choice.png — Xu Yan's first-round context, saved Choice probabilities, and transaction.
- 13-town-round.png — first round of the complete saved Jev/coupon experiment.

`14-policy-comparison-v1.png` is a discarded chart-layout variant. Use the selected milestone layout above for review. Image-generated chart coordinates were not reliable enough to treat as a quantitative plot; a detailed chart, if later desired, should be rendered natively from the archived series.

All selected reference images are generated by the built-in Image Gen tool. Original prompts and reference-image roles are in prompts.json; the final fourth-page revision is in final-page-prompt.txt. Each page is 1672×941, matching the existing presentation canvas (approximately 16:9).

Design data comes from public/data/experiments.json, J0-seed17 and J1-seed17. Extracted figures are in data-reference.json. These are fictional simulation outcomes, not measured real-world policy effects.

Proposed motion:
- Page 11: reveal the town, eight residents and coupon in successive clicks.
- Page 12: focus Xu Yan; context flows to Jev; reveal the four probabilities, chosen action and settlement.
- Page 13: advance or replay one round at a time; residents move to the chosen shops; settled transactions update the large totals.
- Page 14: synchronized paired replay; reveal final totals, round-4 and round-9 milestones, then the paired differences.

User approval is required before implementing the proposed pages. Keep current simulation mechanics and the existing real/saved result distinctions intact.

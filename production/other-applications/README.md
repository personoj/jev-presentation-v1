# 第十五页 · 更多应用

入口：`http://127.0.0.1:4178/#applications`。初始只显示标题；方向键、空格或右下角箭头每次显示一张卡片，六次后完整展示。左箭头逐张撤回，页码按钮重播。自动驾驶已经替换信息提取。

文案与来源的运行时唯一位置：`src/deck/more-applications.ts`。五项源于官方示例，自动驾驶是用户提出的应用设想，描述限定为驾驶仿真；副标题因此使用“更多应用场景”。官方来源可在演示“资料”面板查看。

参考图与图集均使用内置 `image_gen` 生成：
- `source/reference-prompt.txt`：加入自动驾驶的参考图提示词。
- `source/atlas-prompt.txt`：透明图集提示词。
- `public/reference-art/15-applications-atlas.png`：实际网页使用的六幅插图。
- `public/reference-art/ref-15-applications.png`：布局对照图。生成图保留了旧副标题，因此对照模式也以原生文字覆盖为“更多应用场景”，实际页面所有文字均由网页原生渲染。

所有装饰动画均为有限时长，最长1.45秒；之前讲过的卡片保持清晰，返回和重播会取消对应动效。减少动态效果模式直接落到稳定画面。不调用模型、摄像头或车辆设备。

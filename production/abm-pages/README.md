# ABM 四页演示

审批参考：`visuals/abm-review-v1/`。改动前快照：`fd84246`，标签 `abm-pages-before-20260928`。

页面入口：
- `#economy`：小镇、八位居民和消费券；地图人物均可点击。
- `#economy-person`：选中居民的背景 → Jev 行动概率 → 实际结算，三次讲解状态。
- `#economy-round`：先展示本轮开始状态，点击开始；轮次刻度、下一轮、连续回放均可用。居民抵达后更新当轮指标。
- `#economy-compare`：相同初始条件 → 两座小镇和累计成交双线同步回放 → 突出第6轮、第10轮差距及最终增幅。图表从零起步，两组共用同一刻度。

页面顶部“切换居民”提供全部八位居民，跨页保留选择；回合页可回到对应居民与轮次的判断详情。实验台保留原来的自由模拟、多种子对照、保存实验及现场调用。这里的演示回放不调用付费模型。

当前讲解默认使用 `public/data/abm-demo.json` 中的演示模拟。通过 `node --import tsx scripts/build-abm-demo.ts` 可重建：八位居民的购买时点分散在12轮，每轮1–2笔交易；行动与概率由讲解脚本编排，现金、库存、需求上限、消费券有效期和每人一次核销仍由原有结算引擎计算。两组初始居民与商家相同。无券12件/800，有券18件/1210，核销240。第6轮累计相差4件、第10轮相差6件；最终有券组多成交50%，交易额多410。这组数据不代表 Jev 实测。

原始记录仍完整保留在 `public/data/experiments.json` 和实验台。原有 `node scripts/build-abm-presentation.mjs` 仍能生成 `public/data/abm-presentation.json`，保留第17组真实保存请求的概率、请求编号及结算；其来源哈希测试继续通过。两份数据分开保存，不互相覆盖。

静态图层由 Image Gen 从批准稿生成，提示词在 `source/asset-prompts.json`。动态文字、人物、概率条、支付关系、导航、轮次与统计均为原生 DOM/SVG，人物沿用已有的八身份图集。自动回放离页或打开资料面板时停止。减少动态效果模式直接显示稳定位置。

验证截图：`qa/abm-pages/`。主页面 1280×720、1920×1080 验证；选择器在720高视口完整展示八人，不需要滚动。按 O 可叠加或查看原参考图。

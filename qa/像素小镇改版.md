# 试讲截图改版

本轮围绕书页衔接、解释清晰度、稿件跟随、阅读字号和像素小镇重新设计。

## 当前行为

1. 书本运动结束后用 320 ms 渐变交接高清原图，视频不再承担停留阅读。open 与 entered 两种静帧均在进入章节时加载。进入右页后不自动跳转；讲者点击继续才进入三类原语。
2. 场景切换使用短渐变，取消旧的排队导航。实验组件随入口加载，避免转场先显示加载占位、再突变成内容。
3. 不确定性默认显示 10/80/10 与 45/10/45 两组分布，配上用券等级和加权均值公式。流程页可改变余额、库存，并检查交易账本。
4. 跟读主画面移除实时转写栏和 M04 小视频，改成大字稿件、实际文字排版行上的光带、连续下划线和清晰状态仪表。转写仍可在方法详情查阅。位置由原对齐和模型逻辑给出，视觉层不会自行产生进度。
5. ABM 使用内置 ImageGen 的独立像素地图与透明人物图集。人物按本轮意向沿道路移动；居民、建筑均可点击。地图位置是示意，不参与经济效用或账目计算。
6. 保存回放只读取已有快照；对照页显示相同种子的双镇与真实累计差值。讨论页展示可选择的研究设计。

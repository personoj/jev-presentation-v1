## 动作修正

原实现让封面围绕画布中心旋转，同时把整个展开书从另一位置缩放进入，书脊没有共同锚点。现在沿现有图片中测量的书脊上下端投影，封面与左右页共用一个原生动画时钟。左页在封面侧立后展开，文字在纸页接近落定时出现。整体时长 1800 ms，中途反向以当前进度为起点。

没有生成或替换图片，没有改动后续聚焦动画。投影只作用于已有透明图片与相应的页面文字。内页最终坐标仍为原来的 plate 校准；聚焦变换仍为 `matrix(1.65, 0, 0, 1.24, -1029, -26)`。

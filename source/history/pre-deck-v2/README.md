# Jev 组会交互网页

面向 15–20 分钟组会的 **9 幕研究展示**。双击 [启动演示.cmd](启动演示.cmd)，打开 [本机演示](http://127.0.0.1:4178/#opening)。正式构建位于 `dist`。

当前顺序为开场、书页导读、三类问题、概率分布、判断与执行、跟读、政策文本、八人小镇和研究讨论。ABM 的情景、运行与政策对照已合为一页 [自由实验](http://127.0.0.1:4178/#economy)；新增案例暂缓，内容确定后再增加。

- 书本镜头停止后交接高清原图；进入右页后停留，点击才继续。
- 原理页用网页图解说明 Choice、Noul、Score，以及意向如何经过约束成为交易。
- 跟读主画面显示稿件、行焦点和匹配状态；原始转写留在方法详情中。
- 小镇只有 **8 位有固定姓名与性格的居民**。点击人物查看动机、决策习惯、价格／距离／计划系数，以及本轮行动和账目。点击屋顶的小号商家牌，查看价格、库存和经营情况。
- 在同一小镇页切换“自由实验／政策对照”。自由实验可改变消费券和种子、按规则推进、让 Jev 判断选中一人，或载入完整保存实验。政策对照同步播放有券与无券的两个世界。
- 人物具有待机、双帧行走和成交交互图集。动作表现程序记录的状态；位置与步行不额外改变经济机制。

技术栈为 React 19、TypeScript、Vite、Node.js 和 WebSocket。Jev 返回结构化判断，程序处理位置与交易约束；千问 ASR 由本机服务转接。凭据只由服务端读取用户指定文件。

保存实验已按八人版 **`personas8-v1`** 重新运行：种子 17、29、43 × 规则／Jev × 有券／无券，共 **12 条完整轨迹**，每条包含第 0–12 轮的 13 个快照。Jev 条件覆盖有可行选择的居民及需经营调整的商家；现场单人按钮与该完整实验明确区分。回放不发送模型请求，结果不预设为政策一定增加消费。

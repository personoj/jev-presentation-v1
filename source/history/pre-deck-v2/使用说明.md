# Jev 组会网页展示

这是约 18 分钟、9 幕的网页汇报。正文、模型演示与交互场景在同一个前端中运行；可以按顺序讲，也可以从目录进入某一幕。ABM 情景、运行和对照已合并到同一页；后续新案例尚未确定，本版不增加占位演示。

## 双击启动

双击项目内的 **启动演示.cmd**。它会使用本机已有的 Node.js 启动正式构建，并打开默认浏览器：

**http://127.0.0.1:4178/**

启动器先检查 `dist/index.html`，再识别本机运行的应用。若展示已经运行，直接打开现有服务；若没有运行，则在后台启动 `server/index.mjs`。服务日志写入 `.local/server.log`。启动器不安装依赖、不构建源码，也不会关闭占用端口的其他进程。

若提示缺少正式构建，在项目目录运行 `npm run build`，完成后重新双击。若提示 4178 被占用，请检查占用来源，不要结束不明进程。若浏览器没有自动打开，可以手动输入上面的地址。不要直接双击 `dist/index.html`：真实模型接口需要本机服务。

关闭浏览器不会结束后台服务，再次双击会复用它。汇报结束时，先停止麦克风。需要在终端中管理服务时，可在确认后台服务未运行后使用 `npm start`；该前台模式可以用 Ctrl+C 退出。

## 汇报顺序与操作

9 幕依次组织开场、书页导读、三类问题、不确定性、程序与模型的分工、现场跟读、政策文本、八人小镇与讨论。标准 18 分钟版本：前五幕约 5 分 30 秒，跟读 3 分钟，文本 2 分钟，小镇自由实验与对照共 6 分 30 秒，讨论 1 分钟。细分操作见 [当前剧本](剧本.md)。

| 操作 | 用途 |
| --- | --- |
| 右方向键、PageDown | 下一幕；书页处先进入图解镜头 |
| 左方向键、PageUp | 上一幕；书页进入过程中可撤回 |
| 空格 | 非输入控件、按钮和链接聚焦时前进 |
| F | 进入或退出全屏 |
| Esc | 打开目录，或关闭已打开的详情 |
| 右上角“讲者笔记” | 查看当前幕的讲解提示 |
| 底部圆点或“目录” | 直接选择章节 |
| “资料与方法” | 阅读来源、说明与本次运行记录 |

在文本框和选择控件中，键盘保留正常编辑功能。页面支持章节地址与浏览器前进、后退。书本是逐格定格动画：画布按曝光表逐张硬切换画面，不做淡入淡出，可以按当前区域提供的操作翻开、推近或返回；系统启用“减少动态效果”时直接切到静态画面。手机使用较小的逐格图片，重要正文和结果仍为真实网页文字。

## 真实调用与跟读

“向 Jev 提问”“用 Jev 分析这段意见”与 ABM 中标明的“让 Jev 判断某人”会调用 TypeSafe 服务；返回区显示实际结果或行动，完整响应保留在运行记录中。规则推进、数学示例和保存记录回放有各自标签，不冒充实时模型输出。

跟读使用千问实时 ASR。点击“开启麦克风”后，浏览器才会请求麦克风权限；ASR 将声音转写，局部文本对齐寻找稿件位置，Jev 检查有差异的对应关系。它支持少量转写差异，不把所有话题相关的临时插话当作稿件。暂定位置与确认位置分别呈现，阈值属于尚未校准的演示设定。

停止录音后会等待服务端提交最后一句；没有收到结束确认时明确显示错误。离开跟读页面会释放采集资源。现场不方便使用麦克风时，可展开“转写测试”，依次提交原文、局部差异、插话和返回样例。

默认模型为 `jev-latest` 与 `qwen3-asr-flash-realtime`，响应中的版本为实际服务版本。ASR 和 Jev 真实调用需要网络与相应服务额度。视觉视频已在本地生成，正常浏览与回放不重新调用视频生成服务。

## 八人小镇：同一页自由实验

进入 [小镇](http://127.0.0.1:4178/#economy)，顶部只有“自由实验”和“政策对照”两种模式。切换模式保留已选人物和自由实验状态，不需要再翻到运行或对照章节。

文化消费券、人物、商家、价格和意见文本均为虚构研究情景，金额是模拟货币。8 位人物的性格由研究者设定，同一人物跨种子、跨政策保持身份与行为系数；种子只改变小幅初始数值和结算顺序。档案不是模型生成的内心独白。

| 人物 | 特点 | 观察重点 |
| --- | --- | --- |
| 林澈 | 计划阅读者 | 是否坚持原有购书时点 |
| 苏禾 | 即兴文化爱好者 | 当下兴趣与价格怎样改变选择 |
| 周谨 | 审慎藏书者 | 强购书偏好与较低距离敏感度 |
| 唐梨 | 好奇探索者 | 书籍与戏剧之间的选择 |
| 许砚 | 预算敏感者 | 券后实付与剩余现金 |
| 顾宁 | 戏剧社交者 | 戏剧偏好；本实验不模拟朋友邀请 |
| 叶岚 | 务实就近者 | 路程负担是否抵消价格优惠 |
| 陈朔 | 忙碌延后者 | 较后的计划时点与消费券到期 |

点击地图人物或上方头像，右侧显示性格标签、动机、决策习惯、价格／距离／计划相对系数，以及余额、偏好、本轮判断与实际执行。系数的 `1×` 是规则基准，不是概率。屋顶商家牌保持小号；点击牌子，侧栏显示价格、库存或余座、收入、成本与下一轮调整。

1. 在“自由实验”中选择种子 17、29 或 43，并决定是否发券。**切换政策或种子会从第 0 轮重新开始**。
2. “全体按规则推进”计算下一轮。人物沿路移动，成交后切换交互动作。动作来自对应轮次的行动与结算；地图距离不是经济模型中的距离参数。
3. “让 Jev 判断某人”只让选中居民使用真实模型，其余 7 人和商家采用规则。这个按钮会产生模型请求；不会自动执行完整批量实验。
4. “完整实验”可载入已保存轨迹。播放、暂停或拖动轮次只读取已有状态，不发送请求。要继续自由运行，先退出保存回放；回看本机较早轮次时，先返回最新轮次再推进。

地图与角色素材由 ImageGen 制作。动作包括待机、行走 A／B 和成交交互，实际提示词保存在 [八人动作图集说明](source/eight-resident-action-prompts.md)。它们是展示资产，不是模型输出的心理解释。

## 同页政策对照与保存数据

在小镇中切换到“政策对照”，选择决策机制和同一个种子，同步观察有券、无券世界。两个地图同步选中同一人；分别显示余额与行动，档案区注明当前显示的政策世界。可以播放、暂停、拖动轮次，查看当期／累计收入曲线，再将某条轨迹载入自由实验逐人检查。

保存文件采用 **`schemaVersion: 2`、`protocolVersion: personas8-v1`**：3 个种子 × 2 个机制 × 2 个政策条件，共 12 条完整轨迹，每条包含第 0–12 轮快照。Jev 保存实验覆盖有可行消费选择的居民与需调整的商家；受确定约束排除的动作由程序处理。它和现场“选中一人使用 Jev”的范围不同。

8 人版财政初始额度为 240，书店各 4 本初始库存、剧场 6 座。消费券满 60 减 30、每人一次、前 6 轮有效。程序检查预算、库存、需求上限和核销，并保留交易账目。当前结果来自这些设定，可能随种子与机制改变；不能预设消费券一定增加消费，也不能把模拟差值当作现实政策效应。

“本次运行记录”可导出当前页面会话中的输入、结果和执行记录。刷新网页会清空这份会话记录，需要留档时请先导出；项目自带的保存实验文件不受刷新影响。历史 24 人版记录与旧协议不载入当前页面。

## 密钥与常见错误

服务端默认从 **C:/Users/W/Desktop/apikey.txt** 读取指定服务行：`Jev`、`DASHSCOPE_API_KEY`、`ZenMux`。密钥不复制到项目，不发送给浏览器；启动器本身不读取这个文件。也可以在服务进程环境中提供相应变量，或用 `API_KEYS_FILE` 指向另一个本机文件。请不要把密钥粘贴到网页稿件、意见框或运行记录。

| 提示 | 含义与处理 |
| --- | --- |
| NOT_CONFIGURED | 本机服务未读到对应凭据，检查文件位置与服务标识 |
| AUTH_FAILED | 认证失败，检查密钥、账号权限和 ASR 地域 |
| QUOTA_EXCEEDED | 服务额度不足；相关服务在当前进程中停止后续调用，补充额度后再重启本机服务 |
| RATE_LIMITED | 暂时限流，稍后手动重试，不能等同于余额不足 |
| TIMEOUT | 网络或模型未及时完成；结果未被当作成功采用，语音结束确认超时也会明确提示 |
| 麦克风权限被拒绝 | 在浏览器站点设置允许麦克风，或使用转写测试 |

发生额度问题时可以停在当前状态，使用规则运行或已有回放继续讲解，并明确说明来源。不要反复点击真实调用来尝试绕过错误。

## 汇报前检查

先双击启动并等待页面就绪，确认投影比例、中文字体和声音输入设备。试着打开目录、播放书页动效、载入一段保存回放；需要现场真实调用时，提前完成一次小请求与麦克风权限确认。自带视频和保存回放可在无外网时浏览，真实 ASR/Jev 仍需要外网。

开发检查命令为 `npm test` 与 `npm run build`。自动测试覆盖主要状态、接口和启动路径，但不替代实际投影、浏览器权限和当前服务额度检查。

## 画面与操作补充

跟读主画面只显示稿件、行焦点和收音／匹配／暂停／继续状态。原始转写留在方法详情中。可用逐字预览检查跟随效果，再开启麦克风；逐字预览不采集声音。

书本翻开后停在高清书页；再前进一步，镜头逐格推近右页，再硬切到高清近景并停留，点击继续才进入下一幕。小镇的自由实验与政策对照都在第 8 幕，下一幕直接进入研究讨论；后续新例子待内容确定后再加入。

# Jev 组会演示

面向初学者的 11 页浏览器演示：从 System 1 的直观，走到结构化判断与实际应用。

双击 `启动演示.cmd`，打开 http://127.0.0.1:4178/#opening 。正式网页由 `dist` 提供；已有本机服务运行时会直接复用。

- F11 使用浏览器全屏，也可点击右上角“全屏”或按 F。
- 方向键、Page Up / Page Down 或空格逐步推进。动画停下来后，再继续讲解。
- Esc 打开目录，N 打开当前页讲者笔记，Home 回到开场。
- 案例默认展示示意结果；点击“用 Jev 判断”才发出真实请求，画面更新为本次实际返回。
- 语音页保留实时麦克风，新增三个固定转写演示按钮：按稿朗读、临时插话、回到原文。
- 小镇机制与实验记录保持原状；这一版先完成前面的讲解，小镇内容区域仍可滚动。
- 分布公式、购书流程、政策文本分析在“目录 → 备用内容”里。

讲解顺序与讲稿见 `剧本.md`，操作见 `使用说明.md`。制作记录见 `source/deck-v2-production.md`，验收记录见 `qa/deck-v2/验收报告.md`。

React 19、TypeScript、Vite、Node.js。当前入口为 `src/Presentation.tsx`。旧九幕入口仍保留在 `src/App.tsx`，重构前的文档已保存在 `source/history/pre-deck-v2/`。

维护：`npm test`、`npm run build`。开发服务 `npm run dev`（5178），正式页面与接口 `npm start`（4178）。密钥仍仅由本机服务读取，不进入前端。

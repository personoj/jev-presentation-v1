# 演示操作

## 启动与投影

双击项目里的 `启动演示.cmd`，页面从开场进入。按 F11 隐藏浏览器工具栏。新版按 1920×1080、1366×768 和 1280×720 的桌面视口适配；浏览器保持 100% 缩放。

右方向键或空格推进一个讲解步骤。同一页的图解会逐步展开，完成之后才进入下一页。左方向键可以退回上一步。也可以点击页面右下角的箭头，或点击底部短线直接选本页步骤。

按 Esc 打开目录，按 N 查看当前页讲者笔记。目录可以跳到任何一页。地址会保存当前页和步骤，刷新后可继续停在同一步；应用的临时实验结果在刷新后重置。

## 三个小应用

第七页 Choice：选择设备故障、校园卡或选课消息，逐步查看分流。

第八页 Noul：切换两则活动通知，观察明确提供直播和未提到线上参与时的差别。

第九页 Score：先看消息和等级，再显示分数，最后按紧急程度排序。

这些页面默认使用示意值，不依赖网络。需要现场模型结果时点击“用 Jev 判断”。等待期间不展示示意结果冒充真实返回。请求失败可以重试，或点击“回到示意”继续讲解。真实结果可能与示意不同。

“资料 → 本次运行记录”可以检查和导出当前会话中的实际输入输出。

## 语音演示

先用三个固定转写按钮检查画面：点击“按稿朗读”，等第一句完成；点击“临时插话”，观察位置保持；点击“回到原文”，观察继续定位。这三个按钮逐字送入文字，不采集声音。

现场演示时点击“开启麦克风”，按浏览器提示允许当前站点使用麦克风。朗读第一句，临时补充一两句，再接着读第二句。结束后点击“停止录音”，等待最终识别完成。声音通过本机服务转接千问 ASR；Jev 只接收转写文本。

“转写测试”可以检查错字等情况。“查看匹配过程与对照”可以查看识别原文和最近的 Jev 返回。再次点击展开的标题或按 Esc 收起面板。

真实收音效果仍受现场麦克风、噪声、网络和服务状态影响。正式汇报前用将要使用的设备读一遍。

## 小镇与备用内容

第十一页保留八人小镇的自由实验、政策对照、规则推进和保存轨迹。只滚动小镇的内容区域，翻页导航保持可见。

“目录 → 备用内容”保留分数与分布、判断与执行、政策文本分析。需要回答进一步的问题时再打开。

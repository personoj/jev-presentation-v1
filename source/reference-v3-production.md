# 参考图还原版

本次以 `visuals/reference-v3/manifest.json` 的 12 张参考图为构图来源：11 页，以及第二页的书页近景。前十页使用 1672 × 941 的固定画布，等比适配窗口，不通过缩小某些段落或纵向滚动容纳正文。

## 页面怎样构成

背景是一张本地纸张纹理；纸条、夹子、问号、收纳盒、信封、图标和书本是独立透明素材。标题、段落、选项、概率和分数由网页绘制，连接线、刻度和运动点由 SVG 绘制。没有把整页参考图作为正式页面。原参考图只在 O 键验收模式中出现。

素材用内置 ImageGen 生成，最终文件在 `public/reference-art/`，完整提示词在该目录的 `prompts.md`。字体是本地 Noto Serif SC 字体子集，授权文件在 `public/fonts/noto-serif-sc-OFL.txt`；英文主要使用 Times New Roman。

## 每一页怎样讲

1. 封面：先说明今天介绍 Jev，再翻开书。
2. 书页：开书后停住；比较看到涨价的直观和逐项计算预算；聚焦右页；最后点出三种提问方式。同一张高清纸面、同一组文字锚点连续移动。封面转开由独立纸面图层完成；旧版影片仍保存在旧版入口中。
3. Jev 是什么：先给情况，再定义问题，最后由程序读取结果。
4. 输出方式：同一条消息；左侧依次出现文字片段，回到下一步预测；右侧出现问题和候选项概率。
5. 训练目标：已有语言理解能力；RLHF 的候选回答与偏好反馈；RLCD 的决策与概率校准。反馈箭头回到训练标题，不把回答 B 画成回答 A 的来源。
6. 三种类型：Choice 分支、Noul 概率轴、Score 有序等级依次展开。
7. Choice：留言出现、三个去向展开、信封沿选中方向移动，最后说明程序怎样分流。可以换例子或运行 Jev。
8. Noul：通知出现、关键句与概率定位、说明“未写明”和“确认没有”的区别。实际返回会替换指针和读数。
9. Score：三条消息先按原顺序出现，按同一标准评分，然后让原来的纸条重新排序。真实返回同样走这套排序。
10. 语音：声音、转写、判断、稿件位置四步。按稿时光带推进，插话时保持，回到原文后继续定位。麦克风、文本核对与请求失效保护沿用既有实现。
11. 小镇：统一外层纸色、标题和导航，原人物、地图、规则、账目、保存轨迹与模型调用保留。小镇的完整实验区仍可内部滚动。

## 入口与验收

- 默认入口：`/#opening`。
- 旧版保留：`/?legacy#opening`。
- 对照：O 在实际画面、半透明叠图、原参考图之间循环。
- 截图对照页：`/reference-review/index.html`。
- 箭头 / Page Up / Page Down / 空格推进，F 或 F11 全屏，N 查看笔记。
- 点击页码回到本页第一步；打开目录可直接跳页。

参考图中的纹理、阴影与字形由生成模型绘制。实现按其构图与层级校准，但原生字体笔画、重新提取素材的局部纹理不具有逐像素相同的保证；不能把“对照完成”写成“像素完全一致”。实际截图和原图都保留，供直接验收。
